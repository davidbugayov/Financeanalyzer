# Finance Analyzer (Деньги под Контролем)

Веб-приложение для удобного и конфиденциального учета личных финансов, переписанное на стек **React + TypeScript + Vite + Tailwind CSS**.

## 🌐 Описание

**Finance Analyzer** — это автономное приложение для ведения семейного и личного бюджета. Приложение обеспечивает 100% приватность: все данные хранятся локально в вашем браузере (`localStorage`) без передачи на сторонние серверы.

🌍 **Опубликовано:** [https://beszel.emdrbilateral.ru/](https://beszel.emdrbilateral.ru/)

## ✨ Основные возможности

- 💰 **Учет доходов и расходов** с мультивалютностью (RUB ₽, USD $, EUR €, KZT ₸, BYN Br, UAH ₴, GBP £, TRY ₺).
- 🏷️ **Категоризация операций** с выбором подкатегорий, динамическими иконками и цветовым кодированием.
- 💳 **Мульти-счета и кошельки**: карты, наличные, вклады, инвестиции, копилки.
- 🎯 **Цели накоплений** с прогресс-барами, датами дедлайна и правилами **автоматического сбережения дохода** (% от поступлений).
- 🔄 **Переводы между счетами** в один клик.
- 📊 **Наглядная аналитика и статистика**:
  - Круговые диаграммы распределения расходов и доходов (Recharts)
  - Динамика чистого капитала и баланса
  - Расчет **Индекса финансового здоровья** (Financial Health Score)
  - Умные финансовые советы и рекомендации
- 🏆 **Система игровых достижений**: бейджи от «Первые шаги» и «Мастер бюджета» до «Подушка безопасности».
- 🔒 **Безопасность**: опциональная блокировка встроенным 4-значным PIN-кодом.
- 📥 **Импорт выписок банков**: парсинг CSV-выписок из мобильных банков (Тинькофф / Т-Банк, Сбербанк, Альфа-Банк, Универсальный CSV).
- 📤 **Экспорт и резервное копирование**: выгрузка в CSV для Excel/Google Таблиц и полный JSON-бэкап.

## 🛠 Технологический стек

- **Фреймворк:** React 19, TypeScript
- **Сборщик:** Vite
- **Стилизация:** Tailwind CSS
- **Графика и графики:** Recharts
- **Иконки:** Lucide React
- **Хранение данных:** LocalStorage (Offline-first)

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 3000)
npm run dev

# Сборка для продакшена
npm run build
```
